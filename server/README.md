# 联机怎么开（v0.4）

## 一、起中转服务器（只需要一台机器起）

```
cd E:\alien-invasion-3d\server
npm install        # 第一次才要
node relay.mjs     # 默认监听 0.0.0.0:7788
```

想换端口：`node relay.mjs 9000`

服务器只做两件事：配对房间、转发消息。规则全在房主那一端跑。

## 二、两个人各自开游戏

```
E:\alien-invasion-3d\project.godot  用 Godot 打开，F5 运行
```

1. 标题页点「联机」
2. 服务器地址：本机就是 `ws://127.0.0.1:7788`；对方在别的机器上，填房主机器的内网 IP，
   例如 `ws://192.168.1.20:7788`
3. **房主**点「创建房间」→ 屏幕上出现 4 位房间号 → 念给对方
4. **对方**填房间号 → 点「加入」
5. 房主进来后选阵营（人类 / 异形），对方自动坐到对面
6. 双方各自暗选技能（对手看不到你选了什么）
7. 两边都选完 → 自动开局

## 三、对局里谁在动

- 轮流走：轮到谁，谁的 HUD 第一行会写清楚
- 房主那台机器跑全部规则；客机只把自己点的格子发给房主，再把房主发回来的快照画出来
- 所以客机看不到自己不该看的东西：
  - 客机当人类 → 收不到怪物的位置、也收不到怪物走过留下的永久脚印
  - 客机当异形 → 只收到「他查了哪一格、结果是什么」，收不到他没查过的格子
- 对面掉线：画面会停住，中间写「他走了。」

## 四、已知限制

- 房主可以作弊（规则在他那边跑、他能直接看内存）—— 小游戏，无所谓
- 对局中按 R 只重开自己这一台，不会同步给对方
- 公网联机要么把 7788 做端口转发，要么换个能公网访问的地址填进去

## 五、自测脚本（开发用，不用连两个窗口）

```
node test.mjs            # 服务器自身的收发测试
node peer.mjs <房间号>    # 假对手：自动应答 roles/skill/start
node peer2.mjs <房间号>   # 假异形：收到快照就自己朝 (0,0) 走
node host.mjs            # 假房主：建房并发快照，用来单独测客机
```
